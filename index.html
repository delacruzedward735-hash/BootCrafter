Create Bootable USB Drives The Linux Way

BootCrafter Linux is a simple and reliable Linux-native tool for creating bootable USB drives from ISO files and disk images, with explicit target selection, built-in verification, and safety-first disk handling.

Multiple modes. Endless possibilities.

Prepare Linux and Proxmox installers, modern Windows setup media, or restore a USB drive after using it as boot media.

◉

Linux / Proxmox ISO

Byte-for-byte raw writing for hybrid Linux and Proxmox installer images.

▰

Windows UEFI

Creates FAT32 Windows 10/11 installer media and supports split WIM handling.

⚙

USB Recovery

Repartition and format removable media using GPT/MBR and common filesystems.

Safety first, by design.

The GUI stays unprivileged and destructive operations are delegated through PolicyKit only after the selected device is checked again.

✓ Explicit target selection

No destructive target is selected automatically.

✓ System disk protection

System, live, swap, read-only and unsafe internal disks are filtered.

✓ Pre-write validation

Source image, compressed streams and target capacity are validated before erase.

✓ Post-write verification

Raw writes can be read back and compared with SHA-256.
